Import a VCF or vCard file into Google Contacts

By Open Apps Studio · Updated 2026-10-24 · 2 min read

A .vcf file is a vCard contact file that Google Contacts can import. Use the account you want to keep as the destination, preserve the original file, and verify a few complete cards before considering the import finished.

On this page

  1. Check the file and the destination
  2. Use Google Contacts on the web
  3. Verify the fields you rely on
  4. If something is wrong, avoid a blind retry

Check the file and the destination

Confirm that the file actually came from a contacts export. Renaming a document or an Apple Contacts archive to end in .vcf does not convert its contents into vCard format. If your source offers multiple export formats, choose vCard for this workflow.

A single vCard file can contain many people. Its filename does not tell you how many were exported. Record the source list and expected approximate count before importing so you have something meaningful to compare afterward.

Use Google Contacts on the web

On a computer, open Google Contacts, confirm the account, choose Import → Select file, select the .vcf, and complete the import. Wait for it to finish before starting another upload.

If the destination already contains important records, export those first. This gives you a separate baseline if the incoming file overlaps with your existing collection.

Verify the fields you rely on

Check more than names. Compare a card with two phone numbers, a card with a postal address, one with notes, and a card containing accents or a non-Latin name. Check that international prefixes and the distinction between mobile and work numbers remain usable.

Some contact systems represent labels, photos or additional fields differently. If a detail is not where you expected, inspect the full card, including notes, before concluding it was lost. Keep the source available while you compare.

If something is wrong, avoid a blind retry

First determine whether the problem is the entire file, a specific record, or simply the account you are viewing. Try a small export from the original source with one affected card and one ordinary card. This isolates the issue more clearly than importing the whole collection again.

If the first import succeeded, repeating it can create overlapping records. Review the imported set and your backup before removing anything. Use the dedicated import-troubleshooting guide for file-size and formatting checks.

Finally, enable the destination Google account on the iPhone if you want to see its contacts there. Importing a file into Google does not itself configure the phone or establish ongoing synchronization with the original source.
