Move contacts from one Google account to another

By Open Apps Studio · Updated 2026-10-24 · 2 min read

Export the intended contacts from the source Google account and import them into the destination account. This creates a copy. It does not merge the two accounts or redirect future changes automatically.

On this page

  1. Name the source and destination first
  2. Export, switch accounts, then import
  3. Compare the copied records before cleanup
  4. Point future work at the new account

Name the source and destination first

Write down the complete email addresses for the old and new accounts. Similar profile photos and abbreviated names make it easy to export from, or import into, the wrong account. Use separate browser profiles or clearly separated windows if that helps keep the roles obvious.

Check whether the source contains contacts you are allowed to move. A company address book should not be treated as a personal collection simply because you can view it. Export the existing destination too if it already holds important cards.

Export, switch accounts, then import

  1. Open Google Contacts in the source account and select the intended contacts.
  2. Use Export and choose Google CSV.
  3. Save the file with a name that identifies its source and date.
  4. Switch to the destination account, then use Import to select that file.

Keep the original export as a recovery copy. Do not modify the file in a spreadsheet unless there is a specific problem to correct; automatic number formatting can change phone numbers.

Compare the copied records before cleanup

Search for several people in the destination and check their details. Include a contact with more than one email address, one with an international phone number, and one you added recently. Review any duplicate suggestions before accepting them.

If only a portion was copied, investigate which contacts were selected for export. A second full import can obscure the original problem by adding another set of overlapping cards.

Point future work at the new account

On the iPhone, connect the destination account and choose it for new contacts if that is your goal. An old card still visible under the source account does not mean it has moved. Editing that source card later will not update the independent imported copy.

Keep the old account available until the destination is verified. If you want to remove it from the phone, first distinguish hiding its contacts from deleting its cloud records. Do not delete the source collection just to reduce a combined view’s count.

This workflow is for a one-time account move. If you need two accounts to stay aligned, define which account owns the records and evaluate a separate ongoing process.
