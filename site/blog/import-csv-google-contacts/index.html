Import CSV contacts into Google without losing numbers

By Open Apps Studio · Updated 2026-10-24 · 2 min read

Use Google’s contact-import template and keep phone numbers as text. A CSV is a table, so its column names and formatting determine whether contact details land in the intended fields.

On this page

  1. Start with the official field layout
  2. Protect phone numbers while editing
  3. Import a representative sample first
  4. Check completeness without relying only on totals

Start with the official field layout

Get the current template from Google’s import documentation linked below. Retain its header row and put each person’s details into the matching columns. Avoid inventing column names or putting several unrelated values into one cell and expecting the importer to guess.

If your contacts already came from Google, a fresh Google CSV export is usually a better starting point than rebuilding the file from scratch. If you are converting a different source, keep that untouched source alongside the working copy.

Protect phone numbers while editing

Phone numbers are identifiers, not quantities. A spreadsheet can strip a leading zero, interpret a plus sign, or display a long value in scientific notation. Format phone-number columns as text before entering or pasting values.

Compare the saved CSV with the original records, not only the spreadsheet’s display. Include an international number and a number with a leading zero in your test. Do not “normalize” every country’s numbers with one rule unless you know the correct country context.

Also check the character encoding when saving. Names with accents or non-Latin characters should remain legible when the CSV is reopened.

Import a representative sample first

  1. Create a small sample containing ordinary and complex records.
  2. Import it into the intended Google account using the web interface.
  3. Inspect names, phone numbers, email fields and notes on the resulting cards.
  4. Correct the working file if fields are misplaced before importing the remainder.

Track which sample records are already present so the full import does not silently add another copy. Keep the sample distinct enough to identify without altering real important contacts.

Check completeness without relying only on totals

A row count is useful, but blank rows, repeated people and multi-value fields can make totals misleading. Check individual cards and any extra fields you depend on. If the source contains birthdays, addresses or custom notes, include those in your sample.

A successful upload means the file was accepted; it does not prove that every column mapped as you intended. Once verified, keep the final CSV as a dated migration record. For ongoing updates, edit the destination address book or use a deliberate sync workflow rather than repeatedly uploading the same spreadsheet.
