Set Gmail as your default contacts account on iPhone

By Open Apps Studio · Updated 2026-10-24 · 2 min read

Choose Gmail as the Default Account in iPhone Contacts settings to send newly created contacts there by default. Existing cards stay in their current accounts; this setting is not a migration tool.

On this page

  1. When this setting solves the problem
  2. Change the default destination
  3. Test with a new card
  4. Handle older contacts separately

When this setting solves the problem

This is useful when older Google contacts already appear on your phone, but people you recently added only appear in iCloud. The phone can display several address books together while saving new cards to just one default account.

Choose the destination you intend to keep using across devices. For example, if you use Google Contacts in a browser and plan to move between iPhone and Android, saving new personal cards in the same Google account makes them easier to locate later.

Change the default destination

  1. Make sure your Google account is connected with Contacts enabled.
  2. Open Settings → Apps → Contacts → Default Account.
  3. Select the Gmail account you want to use.

If you cannot find the setting, check which contact accounts are enabled. Search Settings for Contacts if your iOS version uses a different menu arrangement. With more than one Google account, verify the email address instead of relying on a similar account label.

Test with a new card

Create a new card named something recognizable, such as “Contact account test,” from the ordinary Contacts view. Give it a harmless note so you can distinguish it from a real person. Check the matching account on Google Contacts in a browser.

Next, create a card using the workflow you normally use, such as saving a caller from the Phone app. Confirm that card reaches the same destination. Apps with their own contact-saving behavior or an explicitly selected account can behave differently from the general default.

Remove your test cards once the result is clear. Do not use a real important contact for repeated delete-and-recreate tests.

Handle older contacts separately

Changing the default does not relocate your existing iCloud cards or combine duplicate records. Before moving older contacts, export the source address book and decide whether you want a one-time copy or ongoing synchronization.

A useful checkpoint is to compare three cards: one older Google contact, one older iCloud contact, and the new test card. Their locations explain whether you need a transfer, a sync repair, or simply this default-account change.
